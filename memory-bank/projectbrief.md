# Project Brief: LangChain Tutorial

## Overview
A hands-on learning project for exploring LangChain, LangGraph, and OpenAI integrations. The project contains practical examples of building AI-powered tools and agents using Python.

## Core Requirements
- Build and experiment with LangChain tools and agents
- Explore different tool creation patterns (@tool decorator, Tool constructor)
- Implement ReAct agents using LangGraph
- Learn LangChain Expression Language (LCEL) for data science workflows
- Integrate with OpenAI models (GPT-4o-mini)

## Project Goals
1. Understand LangChain tool creation and usage patterns
2. Build interactive LLM agents with custom tools
3. Explore zero-shot reasoning and math operations
4. Learn agent orchestration with LangGraph
5. Apply LLM-powered workflows to data science tasks

## Scope
- Educational/tutorial project
- Python-based implementations
- Uses OpenAI API via langchain_openai
- Covers tools, agents, and LCEL patterns
